Built for Full CMake 4.5.1 Workloads

Native build generation, modern language rules, and complete CLI, test, package, and IDE tooling.

5 Native Generators

Direct build-graph emission with deterministic outputs and multi-config generator expression evaluation.

  • Ninja: rspfiles, depfiles, C++20/23 module dyndep
  • Ninja Multi-Config: per-config flags, CMAKE_INTDIR, compile_commands.json
  • Unix Makefiles: implicit dependency scanning and grouped --output-sync
  • Xcode: .xcodeproj/project.pbxproj, schemes, workspaces, XcFramework
  • Visual Studio 17 & 18: .sln, .slnx, .vcxproj, filters, deterministic GUIDs

Languages & Toolchains

Full multi-language compilation rules, module scanning, and cross-compilation toolchain support.

  • C & C++20/23 Modules: CXX_MODULES file sets and CMAKE_CXX_STDLIB_MODULES_JSON
  • Objective-C & Objective-C++: Apple frameworks, Mach-O RPATH, SDK resolution
  • Fortran: .mod dependency scanning, preprocessing, module ordering
  • CUDA & HIP: architectures, separable compilation, device linking
  • ASM / MASM / NASM, Swift, RC & Qt AUTOGEN: AUTOMOC, AUTOUIC, AUTORCC

Modern Tooling & Developer UX

Drop-in compatibility across everyday build, test, packaging, and editor workflows.

  • Multi-Call CLI: cmake (-P, -E, --build, --install, --workflow), ctest, cpack
  • Presets v13 & File-Based API v2.12: codemodel, cache, toolchains, cmakeFiles, configureLog
  • Interchange & Diagnostics: Common Package Specification (CPS), SBOMs, SARIF (--sarif-output), policies CMP0066 to CMP0220+
  • Speed & Introspection: persistent probe cache, incremental replay, rcmake-lsp, and rcmake explain provenance

#![forbid(unsafe_code)]

Enforced across all 34 crates via workspace lints. Untrusted inputs forbid panics, unwrap(), and unbounded recursion across lexing, expressions, presets, and archive parsing.

Host Trait Abstraction

Filesystem, environment, process spawning, and clock access run through a unified Host trait. Native builds use NativeHost; tests, IDE indexing, and WebAssembly use deterministic in-memory PureHost.

Clean-Room Permissive Licensing
