Drop-in CMake 4.5.1 in safe Rust.

One binary runs as cmake, ctest, and cpack. Your CMakeLists.txt files stay the same.

$ git clone https://github.com/dvgyl/rcmake
$ rcmake/scripts/install.sh
$ git clone https://github.com/dvgyl/rcmake
$ cd rcmake && cargo build --release
$ ./target/release/rcmake --version
$ rcmake/scripts/install.sh --alias-cmake
$ ls -l ~/.local/bin
cmake -> rcmake
ctest -> rcmake
cpack -> rcmake

Inside a configure run

Select a stage to see its crates. Every crate forbids unsafe code.

  1. syntax: Lexes and parses CMake language files.
  2. eval: Runs commands and tracks variables, policies, and generator expressions.
  3. resolve: Builds the target graph, usage requirements, and link order.
  4. gen: Writes build.ninja, Makefiles, project.pbxproj, and .vcxproj files.
  5. Host: NativeHost reads disk, environment, processes, and clock. PureHost keeps files in memory for tests, editors, and wasm32.
