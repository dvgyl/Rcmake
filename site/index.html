rcmake

A clean-room replacement for CMake 4.5.1 written in safe Rust. One binary provides cmake, ctest, and cpack.

$ git clone https://github.com/dvgyl/Rcmake
$ Rcmake/scripts/install.sh --alias-cmake
$ cmake -S . -B build -G Ninja && cmake --build build

The installer downloads the latest release into $HOME/.local. Passing --alias-cmake creates cmake, ctest, and cpack links to rcmake.

Architecture

The Rust workspace contains 34 crates. Each stage of a configure run lives in its own crate.

CMakeLists.txt
  -> rcmake-syntax     lex and parse
  -> rcmake-eval       commands, variables, policies, generator expressions
  -> rcmake-resolve    targets, usage requirements, link graph
  -> rcmake-gen-*      build.ninja, Makefile, project.pbxproj, .vcxproj

All stages read files, environment variables, processes, and clocks through Host.
NativeHost runs real builds. PureHost runs unit tests, editors, and wasm32.

Every crate enforces #![forbid(unsafe_code)]. The engine treats CMakeLists.txt files, caches, presets, archives, and process output as untrusted input. Parsers enforce bounds on recursion, expansion, and file size instead of panicking.

The Host trait isolates all operating system access. Unit tests and the browser playground use PureHost, an in-memory host that produces deterministic results.

Known differences from CMake 4.5.1

  • rcmake omits the ccmake terminal interface, cmake-gui, the DAP --debugger flag, and legacy extra generators such as CodeBlocks, Eclipse CDT4, Kate, and Sublime Text.
  • cmake -E tar and CPack archive generators write uid 0 and gid 0 instead of host file ownership so archives stay reproducible.
  • Some upstream Tests/RunCMake cases still differ in output. The compatibility report tracks each suite.
  • rcmake parses Swift targets, but Swift builds are not yet verified against CMake 4.5.1.
  • Running the binary as rcmake enables extra options, including --profile, --no-probe-cache, --fetch-lock, --hermetic, and rcmake explain. Running it as cmake, ctest, or cpack follows CMake 4.5.1.
