Inside a configure run

Eval

Runs commands and tracks variables, policies, and generator expressions.

rcmake-evalrcmake-commandsrcmake-exprrcmake-genexrcmake-modelrcmake-presets
  1. Syntax: Lexes and parses CMake language files.
  2. Eval: Runs commands and tracks variables, policies, and generator expressions.
  3. Resolve: Builds the target graph, usage requirements, and link order.
  4. Generate: Writes build.ninja, Unix Makefiles, project.pbxproj, and .vcxproj files.
  5. Host: NativeHost reads disk, environment, processes, and clock. PureHost keeps files in memory for tests, editors, and wasm32.

Common questions

Is rcmake a drop-in replacement for CMake 4.5.1?

Yes. One rcmake binary dispatches as cmake, ctest, and cpack based on argv[0], reads existing CMakeLists.txt files, Presets v13, and CMakeCache.txt, and writes compatible build trees. When started as cmake, ctest, or cpack, or with RCMAKE_ORACLE_MODE=1, it runs in compatibility mode and matches CMake 4.5.1 behavior and diagnostics.

Which generators, languages, and package managers does rcmake support?

rcmake supports Ninja, Ninja Multi-Config, Unix Makefiles, Xcode on macOS, and Visual Studio 17 2022 and Visual Studio 18 2026 on Windows. It handles C, C++ (including C++20 and C++23 named modules with Ninja dyndep), Objective-C, Objective-C++, Fortran, ASM, MASM, NASM, Windows RC, and Qt AUTOMOC, AUTOUIC, and AUTORCC. It works with existing vcpkg toolchains, Conan fixtures, and FetchContent projects.

How do the shared probe cache and incremental replay speed up configure?

In native mode, rcmake caches verified compiler check outcomes across build directories and projects, checks recorded input files by SHA-256 digest before every reuse, and runs up to four compile probes in parallel by default. On reconfigures after editing a file, incremental replay re-runs the edited region and replays unchanged directory subtrees when their entry context and inputs match. Replay turns off when a toolchain file (such as vcpkg), a configure preset, -C, or PreLoad.cmake is active.

What does rcmake explain do?

rcmake explain <NAME> -B <build> traces where a target gets each compile flag, definition, include directory, or link dependency, and where a variable gets its value across files, macros, functions, and command-line defines. It outputs human-readable text in the terminal or structured JSON with --json, and you can run it directly in the browser playground.

How do I install rcmake and alias cmake, ctest, and cpack?

On Linux and macOS, run curl -fsSL https://raw.githubusercontent.com/dvgyl/rcmake/main/scripts/install.sh | bash to install rcmake, rcmake-lsp, shell completions, and the man page into ~/.local, or append -s -- --alias-cmake after bash to symlink cmake, ctest, and cpack. On Windows, run scripts/install.ps1 (with -AliasCmake for aliases) or extract the x86_64-pc-windows-msvc ZIP archive from GitHub Releases. Intel Macs can build from source with scripts/install.sh --from-source.

What is intentionally different or not implemented in rcmake?

rcmake omits interactive front ends (cmake-gui and ccmake), the --debugger DAP server, legacy extra generators (CodeBlocks, CodeLite, Eclipse CDT4, Kate, Sublime Text 2), older Makefile and Visual Studio 14 to 16 generators, and CPack platform installers NSIS, WIX, productbuild, and IFW (archive generators, External, macOS DragNDrop and Bundle, and Linux DEB and RPM packages are implemented). Its tar and CPack archive writers always record uid 0 and gid 0 for reproducibility, try_compile runs in-process, and Swift builds plus full CUDA and HIP toolchain runs are not yet verified.

Does rcmake contain any unsafe Rust or copied CMake C++ code?

No CMake C++ source is copied or translated, and all 35 rcmake crates enforce #![forbid(unsafe_code)]. Some Rust dependencies such as rustix and memchr use unsafe internally, and the native binary statically links two C compression libraries (zstd 1.5.7 and liblzma 5.8). rcmake bundles the CMake 4.5.1 Modules/, Templates/, and Help/ files verbatim under BSD-3-Clause, while the Rust and Python source is dual-licensed MIT OR Apache-2.0.

Can I run rcmake in WebAssembly or use an editor language server?

Yes. Because all system I/O goes through the rcmake_host::Host trait, rcmake-api compiles with --no-default-features to wasm32-unknown-unknown and wasm32-wasip1 on PureHost and runs the browser playground with no server, supporting live configure, Ninja generation, and explain. For editors, the same multi-call binary provides the language server over stdio when started as rcmake-lsp or rcmake lsp (supporting --help and --version), with hover (including evaluated values), completion, go to definition, symbols, semantic tokens, and formatting for VS Code, Neovim, Helix, Zed, Emacs, and CLion.
