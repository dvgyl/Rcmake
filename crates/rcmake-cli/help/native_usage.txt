
rcmake extensions
  rcmake explain <name> [-B <build-dir>] [--target|--var]
                 [--flag|--define|--include|--dep <val>]
                 [--config <cfg>] [--filter <val>] [--json]
                 [--verbose] [--color=auto|always|never]
  rcmake explain --find <pkg> | why-not <pkg> [-B <build-dir>] [--json]
  rcmake explain --eval '<genex>' [-B <build-dir>] [--target <t>] [--config <cfg>]
                 [--eval-property <prop>] [--json]
  rcmake explain --targets [-B <build-dir>] [-S <source-dir>] [--config <cfg>]
                 [--all] [--json]
  rcmake preset show <name> [--kind configure|build|test|package|workflow]
                 [-S <source-dir>] [--json]
  rcmake diff-config <dirA> <dirB> [--config <cfg>] [--only <sections>] [--json]
  rcmake fmt [--check] [--diff] [--stdin [--stdin-filepath <path>]] [paths...]
  rcmake lint [--sarif] [--deny-warnings] [--list-rules] [paths...]
  rcmake verify [--json] [--timeout <secs>] [--oracle <path>] -- <configure args>
  rcmake doctor [-B <build-dir>]
                               Show tool paths, probe cache, and build drift.
  rcmake cache [status|dir|clear|export <file>|import <file> [--sha256 <hex>]]
                               Inspect, clear, export, or import probe cache.
  rcmake ccmake [options]      Start the interactive cache editor TUI.
  rcmake ctest [options]       Run the bundled ctest driver.
  rcmake cpack [options]       Run the bundled cpack driver.
  rcmake lsp [options]         Start the CMake language server over stdio.
  --diagnostics=cmake|rich     Select the diagnostic format.
  --profile[=<dir>]            Write flamegraph.html, trace.json, and
                               stacks.folded in <dir>, and keep each run in
                               <dir>/run-*. Default: rcmake-profile in build.
  --no-probe-cache             Disable the probe cache for this configure.
  --export-compile-commands    Export compile_commands.json (and per-config
                               databases for multi-config generators).
  --fetch-lock=off|auto|update|frozen
                               Select the fetch lock mode.
  --hermetic[=warn|strict]     Check for undeclared inputs. The default mode
                               for this option is warn.

Environment
  RCMAKE_ORACLE_MODE=1         Run in strict CMake compatibility mode
                               (disables rcmake subcommands and extensions).
