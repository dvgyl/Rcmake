
rcmake extensions
  rcmake explain <name> [-B <build>] [--target|--var]
                 [--config <name>] [--filter <value>] [--json]
                 [--verbose] [--color=auto|always|never]
  --diagnostics=cmake|rich     Select the diagnostic format.
  --profile[=<dir>]            Write flamegraph.html, trace.json, and
                               stacks.folded in <dir>, and keep each run in
                               <dir>/run-*. Default: rcmake-profile in build.
  --no-probe-cache             Disable the probe cache for this configure.
  --fetch-lock=off|auto|update|frozen
                               Select the fetch lock mode.
  --hermetic[=warn|strict]     Check for undeclared inputs. The default mode
                               for this option is warn.
