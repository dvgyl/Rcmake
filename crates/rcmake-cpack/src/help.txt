Usage

  cpack [options]

Options
  -G <generators>     = Override CPACK_GENERATOR
  -C <configs>        = Select build configurations
  -D <var>=<value>    = Set a CPack variable
  --config <file>     = Select the CPack config file
  -P <name>           = Set the package name
  -R <version>        = Set the package version
  -B <dir>            = Set the package directory
  --vendor <name>     = Set the package vendor
  --preset <name>     = Use a package preset
  --presets-file <file> = Select a presets file
  --list-presets      = List available package presets
  -V, --verbose       = Enable verbose output
  --debug             = Enable debug output
  --trace             = Trace CMake scripts
  --trace-expand      = Trace CMake scripts with variables expanded
  --version           = Print the version
  --help              = Print this help

Generators

  ZIP ZIP_DEFLATE ZIP_STORE ZIP_BZ2 ZIP_LZMA ZIP_LZMA2 ZIP_ZSTD
  7Z 7Z_STORE 7Z_DEFLATE 7Z_BZ2 7Z_LZMA 7Z_LZMA2 7Z_ZSTD 7Z_PPMD
